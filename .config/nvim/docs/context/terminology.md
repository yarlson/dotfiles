# Terminology

- **Leader** -- Space key, prefix for most custom keybindings
- **Mason** -- tool installer that manages LSP servers, formatters, linters, and debug adapters
- **Conform** -- formatting engine; runs format-on-save with per-filetype formatter configuration
- **DAP** -- Debug Adapter Protocol; provides debugging via nvim-dap with language-specific adapters
- **Neotest** -- test runner framework; configured with Go and Python adapters
- **Neo-tree** -- file explorer sidebar; auto-opens on startup, follows current file
- **Harpoon** -- quick-access file mark system for frequently visited files
- **Supermaven** -- AI code completion provider, integrated as highest-priority nvim-cmp source
- **Fleet theme** -- JetBrains Fleet-inspired colorscheme; CMP highlights use its palette directly
- **Neogit** -- magit-style git interface with diffview integration
- **Bufferline** -- tab bar showing open buffers with ordinal numbers and LSP diagnostics
- **yaml-companion** -- Telescope extension for switching YAML schemas (K8s, GitLab CI, GitHub Actions, Ansible, Docker Compose)
- **Yar Tree-sitter** -- local Yar grammar checkout at `/Users/yaroslavk/git/yar-treesitter`; provides `.yar` filetype runtime files, parser metadata, and queries
